# スカイライン・テクノロジーズ 企業サイト

## サイト概要

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」の企業サイトのサンプルです。会社情報・実績・数値はすべて創作です。

物流・医療・自治体など、止められない現場の業務システムを設計から運用まで手がける会社を想定した、1ページ構成のサイトです。お知らせ、事業内容、実績、進め方、会社概要・採用情報、お問い合わせのセクションで構成しています。

お問い合わせフォームは見本のため、入力内容はどこにも送信されません。

## 技術構成

| 項目 | 内容 |
| --- | --- |
| マークアップ | HTML |
| スタイル | CSS（`index.html` 内の `<style>` に記述） |
| スクリプト | JavaScript（`index.html` 内の `<script>` に記述、ライブラリ不使用） |
| フォント | Google Fonts の IBM Plex Sans JP、IBM Plex Mono |
| グラフィック | SVG（トップの街並みは JavaScript で生成） |
| ビルド・依存関係 | なし |

ファイルは `index.html` のみで、幅 980px と 760px を境にレイアウトが切り替わります。

## 表示方法

エクスプローラーで `index.html` をダブルクリックすると、既定のブラウザで開きます。

コマンドで開く場合は、このディレクトリで次のコマンドを実行します。

```powershell
# Windows
start index.html
```

```sh
# macOS
open index.html
```

フォントは Google Fonts から読み込むため、オフラインの環境では端末にインストールされている代替フォントで表示されます。
